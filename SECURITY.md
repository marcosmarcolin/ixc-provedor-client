# Política de segurança

## Versões suportadas

Só a versão mais recente recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra uma issue pública. Reporte em particular pelo GitHub, em [Report a vulnerability](https://github.com/marcosmarcolin/ixc-provedor-client/security/advisories/new) (aba **Security** do repositório).

Descreva o problema, como reproduzi-lo e o impacto. Nunca inclua um token real do IXC Provedor nem dados de clientes: use valores fictícios.

Você recebe uma resposta em até 7 dias. Confirmada a vulnerabilidade, a correção sai numa nova versão e o aviso é publicado depois dela, com crédito a quem reportou, se quiser.

Este pacote é só um cliente da API pública. Vulnerabilidades no próprio IXC Provedor devem ser reportadas à IXCSoft.
